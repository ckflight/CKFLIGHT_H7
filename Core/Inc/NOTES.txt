* IMPORTANT: Header file declerations are changed. A header file should include the things like function names.
  Every internally needed header files should be included in .c file not in .h file.
  For example: SPI needs CK_TIME_HAL, CK_GPIO functions so these are included in CK_SPI.c not .h file because
  when a sensor uses SPI it does not need CK_GPIO functions it needs CK_SPI functions. 
  If a sensor needs to use delay function too for example then it should include CK_TIME_HAL.h in its c file.
  In this way complexity and wrong definitions are prevented.
  
  ONLY EXCEPTION TO ABOVE IS: Only include .h file in .h file if others need to see the functions of that included file. 
  For example CK_MATH library does not implement every kind of matematical functions like sqrtf(), pow() etc. 
  So if for example MS5607 includes CK_MATH file then it should be able to reach the  sqrtf(), pow()
  function over CK_MATH.

* To print sprinf float %f i added -u _printf_float to 
  project properties->c/c++ build->setting->tool setting(tab)->mcu gcc linker->miscellaneous->link flag
  
* To create .hex file of code
